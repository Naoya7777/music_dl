# UI設計・操作ガイド（Music DL）

本書は、Music DL（`music_dl`）のGUI画面設計（画面要素、レイアウト、状態遷移）およびWindows環境での導入・起動・基本操作・トラブルシューティング・手動受入試験の手順を定義します。

---

## 1. 画面構成とUIコンポーネント一覧

Music DLは、単一のメインウィンドウ（`ModernUI`）と補助ダイアログですべての操作が完結する構成です。

| 画面/要素ID | 名称 | 主な表示項目・入力コントロール・操作 | 対応要件 |
| :--- | :--- | :--- | :--- |
| **`UI-001`** | **メインウィンドウ** | ・URL入力欄、「貼り付け」ボタン<br/>・音声ビットレート選択（`128k` / `192k` / `320k`）<br/>・保存先フォルダ表示ラベル、「変更」ボタン<br/>・「MP3をダウンロード」開始ボタン<br/>・ステータスバッジ、ステータスメッセージ、進捗バー<br/>・キーボードショートカット：`Enter`（開始）、`Ctrl+L`（URL欄フォーカス） | `FR-01`, `FR-02`, `FR-03`, `FR-06`, `FR-07`, `FR-10` |
| **`UI-002`** | **保存先フォルダ選択ダイアログ** | ・OS標準のフォルダ選択ダイアログ<br/>・選択確定時に `settings.json` をアトミック保存し、成功時のみ画面表示を更新（キャンセル時は変更なし） | `FR-04`, `FR-05` |
| **`UI-003`** | **詳細ログパネル** | ・「詳細ログを表示 / 隠す」トグルボタンによる開閉<br/>・タイムスタンプ、ログレベル（`INFO` / `SUCCESS` / `WARNING` / `ERROR`）、メッセージ一覧<br/>・エラー発生時は自動的にログパネルを展開 | `FR-06`, `NFR-08` |
| **`UI-004`** | **処理中終了確認ダイアログ** | ・ダウンロード/変換中にウィンドウの閉じる（×）ボタンを押した際に表示される確認ダイアログ<br/>・「いいえ」で処理継続、「はい」で即時終了（未完成ファイルの整理は保証しない） | 終了時安全確認 |

### ウィンドウレイアウト仕様

- **外観テーマ**：Darkモード固定（配色・フォント・角丸は `src/ui/theme.py` の `Theme` クラスで一元定義）
- **ウィンドウサイズ**：
  - 初期サイズ（詳細ログ非表示時）：幅 `760px` × 高さ `720px`（最小サイズ：`700px` × `660px`）
  - 詳細ログ展開時：幅 `760px` × 高さ `860px` へ自動拡張
- **縦方向セクション配置**：ヘッダ → URL入力・ダウンロードカード → ステータス・進捗カード → 設定カード（保存先・音質） → 詳細ログパネル

## 2. 画面状態（ステータス）と操作制御

処理の進行状況に応じて、ステータスバッジと各操作コントロールの有効/無効状態が以下のように遷移します。

| ステータス表示 | 状態の意味 | 進捗バーの値 | 入力欄・設定・開始ボタンの制御 |
| :--- | :--- | :--- | :--- |
| **`READY`** | 初期待機状態 | `0.00` | すべて有効（FFmpegが検出されている場合） |
| **`WORKING`** | 音声取得中またはMP3変換中 | 取得中：`0.00`〜`0.94`<br/>変換中：`0.95` | URL欄、貼り付け、保存先変更、音質選択、開始ボタンを**すべて無効化** |
| **`DONE`** | MP3保存完了 | `1.00` | URL入力欄をクリアし、全コントロールを**再有効化** |
| **`CHECK`** | 入力・操作の確認が必要 | `0.00` | 有効（クリップボードが空の場合などに理由を表示） |
| **`ERROR`** | 事前検証失敗、FFmpeg不在、取得/変換失敗、設定保存失敗 | `0.00` | 起動時FFmpeg不在の場合は開始ボタンを**無効化**。<br/>実行時エラーの場合は全コントロールを再有効化し、**詳細ログ（`UI-003`）を自動展開** |

## 3. 環境準備と起動手順（使い方ガイド）

### 3.1 必要な前提環境

導入前に、Windows環境で以下の2つが利用可能であることを確認してください。

| 必須ソフトウェア | 要件 | 確認コマンド（PowerShell） |
| :--- | :--- | :--- |
| **Python** | Python 3.14 および Python Launcher（`py`） | `py -3.14 --version` |
| **FFmpeg** | `ffmpeg.exe` が環境変数 `PATH` に登録されていること | `ffmpeg -version` |

### 3.2 標準起動手順（`run.ps1` による自動準備・起動）

プロジェクトルート（`run.ps1` があるフォルダ）で以下のPowerShellコマンドを実行します。

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

`run.ps1` は自動的に以下の処理を順番に実行します。

1. `py` コマンドと `ffmpeg` コマンドが `PATH` 上に存在するか確認する。
2. `.venv\Scripts\python.exe` が存在しない場合、`py -3.14 -m venv .venv` で仮想環境を作成する。
3. 仮想環境内で `customtkinter` または `yt_dlp` をインポートできない場合、`requirements.txt` から依存パッケージをインストールする。
4. `.venv\Scripts\python.exe -m src.main` を実行してGUIを起動する。

### 3.3 手動での環境構築・直接起動

スクリプトを使わずに手動で仮想環境を準備して起動する場合は、以下のコマンドを実行します。

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m src.main
```

※ 相対インポートを正しく解決するため、`src/main.py` の直接指定ではなく必ず `-m src.main` モジュール形式で起動してください。

## 4. 基本操作手順（MP3のダウンロード）

1. **URLの入力**：保存する権利・許諾を確認済みのYouTube単一動画URLを入力欄に入力するか、「貼り付け」ボタンを押します（`Ctrl+L` でURL欄へ移動可能）。
2. **音質の選択**：音声ビットレートを `128k`、`192k`（初期値）、`320k` から選択します。
3. **保存先の確認・変更**：初期値はユーザーの `Downloads` フォルダです。変更する場合は「変更」ボタンから保存先フォルダを選択します。
4. **ダウンロード開始**：「MP3をダウンロード」ボタンを押すか、`Enter` キーを押します。
5. **完了の確認**：ステータスが `WORKING`（取得中〜変換中 95%）から `DONE`（完了 100%）に変わったら、指定した保存先フォルダ内のMP3ファイルを確認・再生します。

## 5. トラブルシューティング（障害切り分け）

| 症状 | 主な原因 | 確認・対処手順 |
| :--- | :--- | :--- |
| **`run.ps1` 実行時に起動せず終了する** | Python 3.14 または FFmpeg の未導入・PATH未設定、または初回パッケージ導入時の通信エラー | PowerShellで `py -3.14 --version` と `ffmpeg -version` が両方成功するか確認する。既存 `.venv` が破損している場合は `.venv` を削除して再実行する。 |
| **起動直後から開始ボタンが押せない** | 起動時の環境チェックで `ffmpeg` が検出されなかった | `ffmpeg.exe` の配置フォルダをWindowsの環境変数 `PATH` に追加し、アプリを再起動する。 |
| **URLを入力しても開始前にエラーになる** | 空欄、YouTube以外のURL、またはプレイリスト（`list=` を含むURL）が指定されている | `https://www.youtube.com/watch?v=...` または `https://youtu.be/...` 形式の単一動画URLを指定する。 |
| **取得または変換の途中で `ERROR` になる** | 動画の非公開・地域制限、ネットワーク切断、保存先の容量・権限不足、またはYouTube仕様変更 | 自動展開された「詳細ログ」を確認する。ブラウザで動画が再生できるか、保存先に空き容量があるかを確認し、必要に応じて仮想環境内の `yt-dlp` 更新を検討する。 |
| **`settings.json` の設定が初期化された** | JSONファイルの手動編集ミスや不正な値が検出された | 不正値検出時は安全のため既定値（`Downloads` / `192k`）へ自動リセットされる。画面上から再度設定を選択する。 |

## 6. 開発検証コマンドとリリース前手動受入チェックリスト

### 6.1 開発時の自動テスト・静的検査コマンド

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe -m black --check src tests
.\.venv\Scripts\python.exe -m ruff check src tests
.\.venv\Scripts\python.exe -m pyright
```

### 6.2 リリース前の手動受入試験項目

自動単体テストでは外部YouTube通信・実FFmpeg変換・GUI描画をモック化しているため、リリース判断時には権利確認済みの短い動画を用いて以下の9項目を手動確認します。

1. `run.ps1` からエラーなくGUIが起動し、ステータスが `READY` になること。
2. 保存先フォルダと3種類のビットレート（`128k` / `192k` / `320k`）を変更でき、アプリ再起動後も `settings.json` から復元されること。
3. 有効な単一動画URLからMP3ファイルが生成され、音声プレイヤーで正常に再生できること（`FR-02`）。
4. ダウンロード・変換中もウィンドウ移動やログ開閉がフリーズせず応答し、2件目の開始ボタンが無効化されていること（`FR-07`, `NFR-02`）。
5. 完了後にURL欄が空に戻り、続けて別のURLを処理できること。
6. 空URL、YouTube以外のURL、プレイリストURL、無効な保存先を指定した際、開始前に `ERROR` と理由が表示されること（`FR-08`）。
7. 処理中にウィンドウの閉じるボタンを押すと確認ダイアログ（`UI-004`）が表示され、「いいえ」で処理を継続できること。
8. FFmpegをPATHから外した検証環境で起動した際、理由が表示され開始ボタンが無効化されること（`FR-10`）。
9. 通信エラー等を発生させた際、詳細ログ内のURLが `[URL]` にマスクされて表示されること（`NFR-07`）。

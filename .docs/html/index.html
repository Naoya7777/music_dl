music_dl

利用条件を満たすYouTube動画の音声を、Windowsのデスクトップ画面から保存するアプリです。利用者が動画URL、保存先、音質を指定してMP3を取得します。

画面は入力と状態表示を担当します。取得・変換を別スレッドに任せるため、処理中も画面が進行を表示できます。

  1. 入力を確かめる
  2. 音声を取得する
  3. 設定と結果を確認する

主要機能

入力を確かめる

URLと保存先を検証してから処理を開始します。

空白だけの保存先をパスとして解釈する前に拒否します。

音声を取得する

yt-dlpが指定動画の音声を取得し、FFmpegを通じてMP3へ変換します。

外部サービスや変換ツールの異常はエラーとして画面へ返します。

設定と結果を確認する

保存先と音質を設定し、画面に進行・結果・ログを表示します。

並行したダウンロード要求は抑止します。

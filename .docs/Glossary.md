# 用語集（Music DL）

本書は、Music DL（`music_dl`）のドキュメント、ソースコード、設定ファイル、およびGUI画面で使用される用語・状態・識別子の定義をまとめた正本です。

---

## 1. ドメイン・アプリケーション基本用語

| 用語 | コード・設定上の識別子 | 定義・説明 |
| :--- | :--- | :--- |
| **Music DL** | `music_dl` | YouTubeの単一動画から音声を取得し、MP3ファイルとして保存するWindowsデスクトップアプリケーション。 |
| **単一動画URL** | `url` | プレイリスト指定（`list` クエリパラメータ）を含まない、1本のYouTube動画を指すHTTP/HTTPS URL。 |
| **保存先フォルダ** | `save_dir` | 変換後のMP3ファイルを出力するローカルディレクトリ。既定値は `<ユーザーホーム>\Downloads`。 |
| **音声ビットレート（音質）** | `bitrate` | MP3変換時の1秒あたりの音声データ量（単位：kbps）。`128`、`192`（既定値）、`320` の3種類から選択する。画面上は `128k` / `192k` / `320k` と表記される。 |
| **設定ファイル** | `settings.json` | `save_dir` と `bitrate` をJSON形式で永続化するファイル。プロジェクトルートに保存される。 |
| **アトミック置換保存** | `os.replace` | 設定保存時に一時ファイル（`settings.json.tmp`）へ書き込み・同期した後に本番ファイルと入れ替えることで、保存途中のファイル破損を防ぐ手法。 |

---

## 2. 外部ツール・実行環境用語

| 用語 | 識別子 / コマンド | 定義・説明 |
| :--- | :--- | :--- |
| **`yt-dlp`** | `yt_dlp` / `YoutubeDL` | YouTubeから動画情報と音声ストリームを取得し、後処理としてFFmpegを呼び出すPythonライブラリ。 |
| **FFmpeg** | `ffmpeg` | 取得した音声ストリームをMP3フォーマットへエンコード（変換）する外部コマンドラインプログラム。 |
| **環境変数 PATH** | `PATH` | Windowsが `ffmpeg` や `py` などの実行ファイルを探すディレクトリの一覧。 |
| **Python仮想環境** | `.venv` | プロジェクト固有のPythonインタープリタと依存パッケージ（`customtkinter`, `yt-dlp`）をシステム全体から分離して保持するディレクトリ。 |
| **起動スクリプト** | `run.ps1` | Python 3.14とFFmpegの確認、`.venv` の構築、パッケージ導入、およびアプリ起動を一括実行するPowerShellスクリプト。 |
| **DRM** | Digital Rights Management | デジタル著作権管理。コンテンツの複製や視聴を制限する技術的保護手段。Music DLはDRMの回避を行わない。 |

## 3. 内部アーキテクチャ・画面状態用語

| 用語 / 状態名 | 関連クラス・箇所 | 定義・説明 |
| :--- | :--- | :--- |
| **`ModernUI`** | `src/ui/app_window.py` | CustomTkinterを用いてメインウィンドウ、入力欄、進捗バー、詳細ログパネルを構築・制御するGUIクラス。 |
| **`DownloadService`** | `src/core/download_service.py` | 環境検証、`yt-dlp` オプション生成、ワーカースレッド管理、単一ジョブ排他制御を担うサービスクラス。 |
| **ワーカースレッド** | `music-dl-worker` | GUIのフリーズを防ぐため、バックグラウンドで音声取得とMP3変換を実行するデーモンスレッド。 |
| **UI通知キュー** | `_ui_queue` (`queue.Queue`) | ワーカースレッドからメインGUIスレッドへ進捗・ログ・完了イベントを安全に受け渡すスレッド間キュー。50ms周期でポーリングされる。 |
| **`READY`** | UIステータスバッジ | 入力待ちの初期待機状態。 |
| **`WORKING`** | UIステータスバッジ | 音声ダウンロード中（進捗 `0.00`〜`0.94`）またはMP3変換中（進捗 `0.95`）の実行状態。この間、新規操作はロックされる。 |
| **`DONE`** | UIステータスバッジ | MP3の変換・保存が正常に完了した状態（進捗 `1.00`）。 |
| **`CHECK`** | UIステータスバッジ | クリップボードが空であるなど、利用者の確認・再操作を促す注意状態。 |
| **`ERROR`** | UIステータスバッジ | 入力検証エラー、FFmpeg未検出、設定保存失敗、または取得・変換失敗を示すエラー状態。 |
| **URLマスキング** | `_safe_error_message()` | プライバシー保護のため、例外メッセージ内に含まれる `http://` / `https://` URLを `[URL]` という文字列に置換する処理。 |

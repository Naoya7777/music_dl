# music_dl 詳細設計書

## 1. システム構成

src/main.pyが入口です。画面はsrc/ui、入力検査・設定・取得処理はsrc/coreに分離します。

## 2. 機能別の詳細設計

画面が入力を渡し、取得サービスが多重実行を検査してワーカーを開始します。yt-dlpとFFmpegで音声を処理します。

## 3. データと情報管理

AppConfigが設定を表し、ConfigManagerが保存・読込みを担当します。進行と結果はコールバックから画面キューに渡します。

## 4. 処理の流れと判断条件

URL、保存先、依存ツールの条件を満たしてから処理を始めます。終了時に画面が操作可能な状態に戻ります。

## 5. 状態管理と例外処理

待機、処理中、完了、要確認、エラーを表示します。設定保存の失敗と処理失敗は個別に報告します。

## 6. 安全性と障害対応

不正URLや空欄を拒否し、公開可能なエラー文に整理します。異常時は入力と環境を確かめます。

## 7. 技術上の制約

動画配信の仕様変更、配信制限、FFmpeg環境に影響を受けます。ログの恒久保存は保証されません。

# music_dl 用語・定義集

## 1. 主要な機能・業務用語

- **yt-dlp**。動画音声の取得を担うライブラリ。
- **FFmpeg**。音声の変換を担うツール。

## 2. 技術用語・略語

- **保存先**。成果物を書き込むディレクトリ。
- **コールバック**。処理中・終了時に結果を画面へ伝える入口。

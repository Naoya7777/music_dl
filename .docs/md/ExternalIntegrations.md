# music_dl 外部サービス・API連携設計書

## 1. 外部連携の全体像

YouTubeへの取得要求とローカルのFFmpegによる変換で構成します。

## 2. 連携先と利用目的

yt-dlpで音声を取得し、FFmpegの変換後にローカル保存先へ書き込みます。

## 3. 接続方法と認証

URLとローカル実行環境を使います。通常フローの利用者によるAPIキー入力画面はありません。

## 4. データ交換と処理

URL、出力先、音質を取得・変換設定に渡し、進行と終了結果を画面に通知します。

## 5. 障害対応と安全条件

URL、依存ツール、保存先を確認します。失敗した処理は結果とログで切り分けます。

## 6. 運用上の制約

実通信・変換・再生の確認には利用条件を満たす対象と適切な環境が必要です。

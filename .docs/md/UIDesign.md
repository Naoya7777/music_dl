# music_dl UI設計書

## 1. UIの目的と設計方針

CustomTkinterのメインウィンドウで、入力と進行状況をまとめて扱います。

## 2. 画面一覧

URL入力、ダウンロード操作、保存先と音質、状態、ログの各領域があります。

## 3. 画面別の機能と表示内容

- **入力を確かめる**。URLと保存先を検証してから処理を開始します。
- **音声を取得する**。yt-dlpが指定動画の音声を取得し、FFmpegを通じてMP3へ変換します。
- **設定と結果を確認する**。保存先と音質を設定し、画面に進行・結果・ログを表示します。

## 4. 操作方法と画面遷移

URLを入力し、保存先と音質を確認してダウンロードします。

## 5. 表示状態と例外表示

処理中は操作を制御し、終了時は成功または失敗とログを確認できます。

## 6. 操作性と対応環境

Windowsの起動スクリプトと依存環境を使用します。ブラウザUIはありません。

# music_dl 要件定義書

## 1. 目的と対象範囲

動画URLから音声を取得し、指定条件で手元に保存できることが対象です。

## 2. 機能要件

入力検証、設定保存、取得・変換、進行・完了・異常表示が必要です。

## 3. 非機能要件

画面スレッドを長時間の取得・変換で塞がず、入力異常を実行前に表示します。

## 4. 外部連携要件

YouTubeへの接続にyt-dlpを使い、FFmpegがMP3へ変換できることを確認します。

## 5. 制約と安全条件

利用権限のあるコンテンツと書込み可能な保存先を利用します。

## 6. 受入条件

空白だけの保存先を拒否し、検証済みの入力で処理を開始します。GUI操作と実通信・再生は個別の検証項目です。

## 7. 未決定事項

追加開発は未指定です。外部サービスの実動作は検証環境で確認します。

## 利用前の注意

Music DL は、単一の YouTube 動画から音声を取得し、
MP3 として保存するデスクトップアプリケーションです。

対象コンテンツを保存する権利または必要な許諾を持つ場合に限り使用してください。YouTube の
利用規約、著作権法、その他の適用法令を確認し、DRM の回避や無断複製には使用しないでください。

## 前提条件

- Windows
- Python 3.14 を基準とする実行環境
- インターネット接続
- Python パッケージ `customtkinter` と `yt-dlp`
- FFmpeg
- 出力ファイルを保存できる権限と十分なディスク空き容量

Python と依存ライブラリの互換性は更新により変わる可能性があります。プロジェクトの基準は
Python 3.14 ですが、導入時点で `customtkinter` と `yt-dlp` の対応状況を確認してください。

## インストール

### 最短の起動方法

Python 3.14とFFmpegを導入後、プロジェクトのルートで次の1コマンドを実行します。

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

初回は仮想環境と実行用Pythonパッケージを自動的に準備します。以下は手動で環境を構築する
場合の手順です。

### 1. 仮想環境を作成する

プロジェクトのルートディレクトリで PowerShell を開き、次を実行します。

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

PowerShell の実行ポリシーにより有効化できない場合は、仮想環境の Python を直接指定して
以降のコマンドを実行できます。

### 2. Python パッケージを導入する

```powershell
python -m pip install -r requirements.txt
```

`requirements.txt` には検証済みの実行依存バージョンを固定しています。

### 3. FFmpeg を導入する

信頼できる配布元から Windows 用 FFmpeg を導入し、`ffmpeg.exe` を含むフォルダを PATH に
追加します。新しい PowerShell を開き、次のコマンドが成功することを確認します。

```powershell
ffmpeg -version
```

アプリケーション起動後に「FFmpegが未インストールです」と表示される場合、アプリケーションを
いったん終了し、PATH 設定後に起動し直してください。

## 起動方法

プロジェクトのルートディレクトリで次を実行します。

```powershell
python -m src.main
```

`src/main.py` をファイルとして直接実行すると、相対 import を解決できない場合があります。
モジュール形式で起動してください。

## 基本操作

1. YouTube の単一動画 URL を入力欄に貼り付けます。「貼り付け」ボタンも利用できます。
2. 必要に応じて 128 kbps、192 kbps、320 kbps から音質を選びます。既定値は 192 kbps です。
3. 「保存先」を選択し、出力フォルダを指定します。初期値は利用者ホーム配下の
   `Downloads` フォルダです。
4. 「MP3をダウンロード」を選択します。
5. ステータスと進捗バーを確認します。処理中は追加のダウンロードを開始できません。
6. 「MP3 の保存が完了しました」と表示されたら、保存先の MP3 ファイルを確認します。

ビットレートを高くすると一般にファイル容量は増えます。入力音源の品質を超える音質が保証
されるわけではありません。

## 設定と保存データ

保存先とビットレートは、起動時の作業ディレクトリにある `settings.json` へ保存されます。
通常はプロジェクトのルートディレクトリから起動するため、同ディレクトリに作成されます。

設定例は次のとおりです。

```json
{
  "save_dir": "C:\\Users\\user\\Downloads",
  "bitrate": "192"
}
```

このファイルに秘密情報を記載しないでください。設定が破損した場合、アプリケーションを終了し、
`settings.json` を別名で退避してから再起動すると既定値に戻せます。退避前の保存先と音質は
自動復元されません。

## 詳細ログ

「詳細ログを表示」を選択すると、処理開始、設定変更、保存完了、エラーを確認できます。
ログは画面内だけに保持され、ファイルへは保存されません。アプリケーションを終了すると失われます。

外部ライブラリのエラーに含まれるURLは画面表示前にマスクします。それ以外のファイル名や
環境情報が含まれる場合があるため、問い合わせや画面共有の前に公開してよい内容か確認してください。

## 制約

- 一度に処理できる URL は1件です。
- プレイリストは処理しません。
- 出力形式は MP3 のみです。
- 一時停止、再開、キャンセル、履歴管理はありません。
- YouTube以外のURL、動画を特定できないURL、プレイリスト付きURLは開始前に拒否します。
- アプリケーション終了時に実行中の処理を待機しません。処理中は終了しないでください。
- ダウンロード可否はネットワーク、接続先サービス、`yt-dlp`、FFmpeg に依存します。

## トラブルシューティング

### ダウンロードボタンが無効になっている

画面の警告と詳細ログを確認してください。FFmpeg が見つからない場合は、`ffmpeg -version` が
新しい PowerShell で成功するよう PATH を設定し、アプリケーションを再起動します。

### ダウンロードに失敗する

次の順に確認します。

1. URL が空でなく、ブラウザで対象動画を開けるか確認します。
2. プレイリストではなく、単一動画の URL を使用します。
3. インターネット接続を確認します。
4. 保存先フォルダの書き込み権限と空き容量を確認します。
5. 詳細ログのエラーを確認します。
6. 検証済み範囲で `yt-dlp` の更新を検討します。

更新によって互換性が変わる可能性があるため、本番利用環境では更新前のバージョンと動作確認
結果を記録してください。

### 設定が保存されない

アプリケーションを起動したディレクトリへの書き込み権限を確認します。設定保存エラーは、
ステータスと詳細ログに表示されます。保存時は一時ファイルから置換するため、失敗時に既存の
設定を途中まで上書きしません。

### 出力ファイルが見つからない

画面の「保存先」を確認してください。ファイル名は動画タイトルを基に生成されます。タイトルに
ファイル名として使用できない文字がある場合の変換は `yt-dlp` が処理します。

## 動作確認

### 自動テスト

最初に固定済みの開発依存関係を導入します。

```powershell
python -m pip install -r requirements-dev.txt
```

プロジェクトのルートで次を実行します。

```powershell
python -m pytest
```

整形、lint、型チェックは次のコマンドで確認します。

```powershell
python -m black --check src tests
python -m ruff check src tests
pyright
```

単体テストは外部サービスへの実接続や実際の MP3 変換を行いません。

### リリース前の手動確認

権利または許諾を確認済みの短いテスト動画を使用し、次を確認します。

1. アプリケーションが起動し、FFmpeg のシステムチェックを通過する。
2. 保存先と各音質設定を変更できる。
3. 単一動画を処理し、指定先に MP3 が生成される。
4. MP3 を再生できる。
5. 完了表示後に次の URL を入力できる。
6. アプリケーションを再起動すると保存先と音質が復元される。
7. 空の URL と到達不能な URL で、利用者が失敗を識別できる。

## サポート時に記録する情報

障害を報告する場合は、秘密情報や個人情報を除き、次を記録します。

- 発生日時とタイムゾーン
- Windows、Python、`yt-dlp`、FFmpeg のバージョン
- 実行した操作と期待した結果
- 実際の画面表示と詳細ログ
- 保存先の権限と空き容量の確認結果
- 再現性の有無

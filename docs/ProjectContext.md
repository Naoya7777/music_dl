## 背景と解決する課題

Music DL は、利用者が権利または許諾を持つ
YouTube 動画から音声を取り出し、ローカル環境へ MP3 ファイルとして保存する Windows
向けデスクトップアプリケーションです。

コマンドライン操作や `yt-dlp`、FFmpeg の個別設定に不慣れな利用者に対し、URL入力、
音質選択、保存先指定を一つの画面にまとめ、音声保存までの操作を簡略化します。

## 目的と成功指標

本サービスの目的は、対象動画の URL を入力してから、選択した音質の MP3 ファイルを
指定フォルダへ保存するまでの操作を、デスクトップ画面上で完結させることです。

現段階の成功指標は次のとおりです。

- 対応する単一動画 URL から音声を取得し、MP3 へ変換できる。
- 128 kbps、192 kbps、320 kbps のいずれかを指定できる。
- 保存先と音質の設定を次回起動時に復元できる。
- 処理中の状態、完了、失敗を画面で確認できる。
- UI がダウンロード処理中も操作不能にならない。

処理時間や成功率の数値目標は未定です。運用データを収集できる仕組みも現時点では
ないため、数値目標を導入する場合は計測方法と併せて定義します。

## 想定利用者と関係者

- **主な利用者**: Windows PC 上で、自身が利用権限を持つ動画の音声を個人利用の
  範囲で保存したい利用者
- **開発者**: UI、設定永続化、ダウンロード処理、テストを保守する担当者
- **運用担当者**: Python、FFmpeg、依存パッケージの導入と障害一次切り分けを行う担当者
- **外部サービス提供者**: YouTube、`yt-dlp`、FFmpeg の各提供者

## 対象範囲

### 対象

- YouTube の単一動画 URL の入力およびクリップボードからの貼り付け
- `yt-dlp` による利用可能な最良音声ストリームの取得
- FFmpeg による MP3 への変換
- 128 kbps、192 kbps、320 kbps の品質選択
- 保存先フォルダの選択
- 進捗、残り時間の推定、完了、エラーの画面表示
- 保存先と品質設定のローカル JSON ファイルへの保存
- 起動時の FFmpeg 存在確認

### 対象外

- プレイリストや複数 URL の一括処理
- MP3 以外の出力形式
- 動画ファイルの保存
- 字幕、サムネイル、歌詞、メタデータの編集
- ダウンロードの一時停止、再開、キャンセル
- ユーザー認証、クラウド同期、履歴管理
- DRM（デジタル著作権管理）の回避
- コンテンツの権利確認や利用許諾の代行

## 利用シナリオ

1. 利用者がデスクトップショートカット、または `run.ps1` を使って起動します。
2. `run.ps1` が仮想環境とPythonパッケージを必要に応じて準備します。
3. アプリケーションが FFmpeg の存在を確認します。見つからない場合は処理を無効化します。
4. 利用者が単一動画の URL を入力または貼り付けます。
5. 必要に応じて音質と保存先を変更します。
6. 利用者が「MP3をダウンロード」を選択します。
7. アプリケーションが音声を取得し、MP3 に変換します。
8. アプリケーションが結果を表示し、成功時は指定フォルダにファイルを残します。

## 用語

| 用語 | 定義 |
| --- | --- |
| ビットレート | 1秒当たりの音声データ量。一般に値が大きいほどファイル容量も大きくなる |
| FFmpeg | 取得した音声を MP3 に変換する外部プログラム |
| `yt-dlp` | 対応サイトからメディア情報や音声を取得する外部ライブラリ |
| 保存先 | 完成した MP3 ファイルを配置するローカルフォルダ |

## 機能要求

| ID | 要求 | 現在の実装 |
| --- | --- | --- |
| FR-01 | 単一動画 URL を入力できる | テキスト入力と貼り付けボタンを提供 |
| FR-02 | 音声を取得して MP3 に変換できる | `yt-dlp` と FFmpeg を使用 |
| FR-03 | 3段階のビットレートを選べる | 128、192、320 kbps |
| FR-04 | 保存先を選択できる | フォルダ選択画面を使用 |
| FR-05 | 設定を次回起動時に復元できる | `settings.json` に保存 |
| FR-06 | 処理状態と結果を確認できる | ステータス、進捗バー、詳細ログを表示 |
| FR-07 | 同時に複数処理を開始させない | ロック、実行中フラグ、操作無効化で制御 |
| FR-08 | 対象外の入力を処理前に拒否する | YouTube単一動画URL、音質、保存先を境界で検証 |
| FR-09 | 1操作または1コマンドで起動できる | ショートカットから `run.ps1` を呼び、環境準備後に起動 |

## 非機能要求

- **対応環境**: Windows、Python 3.14 を基準とします。
- **応答性**: ダウンロードと変換はバックグラウンドスレッドで実行し、画面処理を
  長時間占有しないものとします。UI更新はキュー経由でUIスレッドへ集約します。
- **安全性**: 認証情報を設定やログへ保存しません。利用者が指定した保存先以外への
  意図しない永続化を行わず、エラーログに含まれるURLをマスクします。
- **データ整合性**: 設定は検証済みの不変オブジェクトとして扱い、一時ファイルを書き込んで
  から原子的に置換します。
- **可用性**: YouTube、ネットワーク、`yt-dlp`、FFmpeg の状態に依存します。
  オフライン動作は対象外です。通信は30秒でタイムアウトし、取得失敗は最大3回再試行します。
- **保守性**: UI、ダウンロード処理、設定管理を分離し、主要ロジックは単体テスト可能な
  境界を維持します。
- **アクセシビリティ**: 現状はダークテーマ固定で、キーボード操作やスクリーンリーダーの
  適合基準は未定です。
- **プライバシー**: アプリケーション独自の分析情報送信は行いません。ただし、動画取得時は
  接続先サービスへ URL や通常の通信情報が送信されます。

## 前提条件、制約、依存関係

- 利用者が対象コンテンツを保存する権利または必要な許諾を持ち、YouTube の利用規約、
  著作権法その他の適用法令を順守することを前提とします。
- Python パッケージ `customtkinter` と `yt-dlp`、およびシステム上の FFmpeg が必要です。
- 対応可否は `yt-dlp` と接続先サービスの仕様変更に影響されます。
- 出力先に十分な空き容量と書き込み権限が必要です。
- ファイル名は取得した動画タイトルを基に `yt-dlp` が生成します。同名ファイルの扱いは
  `yt-dlp` の挙動に依存します。
- 設定ファイルは起動時の作業ディレクトリに作成されます。

## 受入条件

- FFmpeg が利用できる環境で、有効な対応 URL を入力すると、指定先に再生可能な MP3 が
  生成される。
- 選択したビットレートが変換設定へ渡される。
- 保存先または音質を変更すると `settings.json` に反映され、次回読込時に復元される。
- URL が空の場合は処理を開始せず、入力を促す表示を行う。
- FFmpeg が見つからない場合は理由を表示し、ダウンロードボタンを無効化する。
- 処理成功時と失敗時に、利用者が結果を識別できる表示を行う。
- 実行中に追加の処理を開始しない。

実サービスへの接続を伴う受入試験では、権利を確認済みのテスト動画を使用します。

## 採用方針とトレードオフ

- **デスクトップ UI**: ブラウザやサーバーを用意せず利用できますが、配布と環境構築は
  各 PC で必要です。
- **`yt-dlp` の利用**: サイト固有処理を自前実装せずに済みますが、外部サービスの変更に
  追随するため継続的な更新が必要です。
- **FFmpeg の外部導入**: 実績ある変換機能を利用できますが、Python パッケージとは別に
  インストールと PATH 設定が必要です。
- **JSON 設定**: 容易に確認・復旧できますが、スキーマ検証、暗号化、複数利用者の分離は
  提供しません。
- **バックグラウンドスレッド**: UI の応答性を維持できますが、状態同期が必要です。
  実行状態はロック、画面通知はスレッド安全なキューで分離します。

## リスク、未決事項、今後の課題

- URL 検証はホスト名とURL構造に基づくため、動画の存在、公開状態、利用権限までは
  事前判定できません。
- 30秒の通信タイムアウトと最大3回の再試行を設定していますが、レート制限専用の待機制御は
  実装していません。
- 変換失敗時の一時ファイルや部分ファイルの扱いを明文化していません。
- 設定読込エラーは画面ログ、保存エラーはステータスと画面ログへ通知しますが、永続ログは
  提供していません。
- Python 3.14 と依存ライブラリの互換性、および依存バージョンの固定方針を継続確認する
  必要があります。
- 配布形式、コード署名、自動更新、アクセシビリティ基準、性能目標は未決です。
